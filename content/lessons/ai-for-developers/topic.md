For developers who want to build with AI or work in it. You'll learn the Python and math that ML work rests on, how models are trained and judged, how deep learning looks in PyTorch, and how to build real products on large language models: prompting from code, tool use, retrieval (RAG), and evals. It ends with what AI and ML jobs ask for and how to show you can do the work.

<!-- outline -->

1. The AI job map (Beginner): AI engineer, ML engineer, data scientist, researcher; what each does day to day
2. Python for ML (Beginner): NumPy arrays, pandas, notebooks, why Python dominates
3. The math you actually need (Beginner): vectors, matrices, dot products, probability, gradients
4. Your first model with scikit-learn (Beginner): train/test split, fit, predict, accuracy vs. precision and recall
5. Training a network in PyTorch (Intermediate): tensors, the training loop, loss, optimizers, GPUs
6. Calling an LLM from code (Intermediate): API requests, system prompts, tokens and cost, streaming
7. Tool use and agents (Intermediate): letting a model call your functions, loops, guardrails
8. Retrieval-augmented generation (Intermediate): embeddings, vector search, chunking, citing sources
9. Evals: knowing if it works (Advanced): test sets for LLM features, graders, regressions
10. Fine-tuning vs. prompting vs. RAG (Advanced): when each is worth it, LoRA, costs
11. Shipping AI to production (Advanced): latency, cost, monitoring, safety, privacy
12. Getting hired (Intermediate): portfolio projects, write-ups, interviews, where to start this month
