Writing code is only part of the job. This path covers the skills that decide how far you go as an engineer: reviewing code so people want your feedback, estimating work without guessing, finding bugs on purpose instead of by luck, reasoning about system design trade-offs, and moving through interviews and offers with a plan.

<!-- outline -->

1. Code review and giving feedback (Beginner): what to look for, how to word comments, reviewing your own PR first
2. Estimating and scoping work (Intermediate): breaking work down, ranges instead of single numbers, cutting scope
3. Debugging methodically (Beginner): reproduce, narrow down, one change at a time, writing down what you learn
4. System design basics (Intermediate): caching, choosing a database, queues, and the trade-off each one buys
5. Interviews and career moves (Intermediate): technical interviews, résumés that get read, negotiating an offer
